# 🗺️ AI Context Brain — Product Roadmap

This roadmap outlines the planned features, enhancements, and milestones for AI Context Brain.

## 🚀 Q3 2026 — Public Beta & Integrations
- [x] **Core Context Extraction** — Local filesystem analysis, dependency tracking.
- [x] **IDE Integrations** — VS Code Extension release.
- [x] **AI Rule Engine** — Folder restrictions, content forbidden, naming paradigms, import constraints.
- [x] **Context Versioning** — Context history snapshots and diff comparisons.
- [ ] **Multi-root Workspace Support** — Better context scanning for monorepos.
- [ ] **Advanced Rule Types** — Custom AI rule validation and syntax checks.

## 🎯 Q4 2026 — Team Features & SaaS Expansion
- [x] **Team Workspace Collaboration** — Shared project memories, roles, invitations.
- [ ] **JetBrains IDE Extension** — Support for IntelliJ, WebStorm, PyCharm.
- [ ] **CLI Scan Tool** — Headless CLI scanner for CI/CD pipeline integrations.
- [ ] **Enterprise Identity** — SSO, SAML integrations, audit logs.

## 🔮 Q1 2027 — Deep AI Analytics & Agents
- [ ] **Interactive Context Chat** — Chat with codebase context in the dashboard.
- [ ] **Incremental Context Graph** — High-performance incremental dependency mapping.
- [ ] **Agentic Mode API** — Multi-agent integrations (Aider, Claude Code) with live workspace permissions.
- [ ] **Custom Fine-tuning Exports** — Export tailored context structures to fine-tune private LLMs.

---
*Note: This roadmap is subject to change based on developer feedback and marketplace evolution. Join the public beta to influence features!*
